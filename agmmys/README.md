# AGMMYS website (agmmys.org)
Static HTML/CSS/JS. No build step or backend. Open `index.html` or host the folder as is.
- **Colours/fonts:** `assets/css/style.css` (`:root` tokens).
- **Header/footer:** repeated in every page; edit all pages when changing them.
- **Add an event/initiative/leader:** copy an `<article class="card">` in its section and edit the text.
- **Placeholders:** search for `[` and `Placeholder` to find items awaiting official details (names, contacts, address, legal entity, app-store links, dates).
- **Contact links:** replace the sample `tel:`, `wa.me` and `mailto:` values on `contact.html`.
- **Legal pages:** drafts only. Have qualified counsel review before publishing.
- **Images:** `assets/images/logo.png` is the supplied logo, unaltered. Favicons are resized copies.
- **SEO:** canonical, Open Graph, Organization schema (name, URL, logo only), `sitemap.xml`, `robots.txt`.
